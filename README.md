# CV en ligne — Florent Vidal

CV personnel de développeur web, codé en HTML et CSS sans framework.

**Version en ligne :** https://florent-vidal.github.io/cv-florent-vidal/

## Caractéristiques

- HTML sémantique : `header`, `main`, `aside`, `section`, `address`, `time`
- CSS sans framework, avec des variables pour les couleurs
- Responsive : adaptation mobile en dessous de 768 px
- Styles d'impression dédiés : mise en page A4, adresses des liens affichées sur papier
- Accessibilité : textes alternatifs, `aria-label` sur les niveaux de compétence
- Polices variables auto-hébergées (Wix Madefor Display, Mozilla Text)

## Structure

```
cv-florent-vidal/
├── index.html
└── assets/
    ├── styles/styles.css
    ├── font/
    ├── icons/
    ├── img/
    └── favicon/
```

## Lancer en local

Aucune installation nécessaire : ouvrir `index.html` dans un navigateur.
